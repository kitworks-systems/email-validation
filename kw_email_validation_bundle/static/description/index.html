Email Validation Bundle


This module provides a complete bundle of all email validation modules for Odoo. It's designed as a convenience package that installs the base email validation module along with all integration modules, giving you comprehensive email validation capabilities across your entire Odoo system with a single installation.

Key features include:

  • One-click installation of all email validation modules
  • Complete validation coverage for all standard Odoo modules
  • Multiple validation methods (API, DNS, SMTP)
  • Web interface for manual validation
  • Consistent validation experience across all Odoo modules

Included Modules

Core Functionality

  • kw_email_validation: Base module with core validation functionality
  • kw_email_validation_web: Web interface for email validation

Validation Methods

  • kw_email_validation_dnspython: DNS-based validation
  • kw_email_validation_smtp: SMTP-based validation

Module Integrations

  • kw_email_validation_contacts: Validation for contacts (res.partner)
  • kw_email_validation_crm: Validation for CRM leads
  • kw_email_validation_hr: Validation for employees
  • kw_email_validation_hr_recruitment: Validation for job applicants
  • kw_email_validation_event: Validation for event registrations
  • kw_email_validation_mass_mailing: Validation for mailing contacts

Benefits of the Bundle

  • Simplified Installation: Install all modules with a single click
  • Consistent Configuration: Unified configuration across all modules
  • Complete Coverage: Validate emails in all standard Odoo modules
  • Multiple Validation Methods: Use the best validation method for each scenario
  • Comprehensive Solution: Address all email validation needs in one package

Technical Details

This is a meta-module that depends on all other email validation modules. It doesn't add any functionality itself but ensures that all email validation modules are installed and properly configured.

Implementation

  • Automatic validation of email addresses across all supported models
  • Visual indicators for validation status in all relevant forms and lists
  • Manual validation through action menus where applicable
  • Automatic validation of existing emails upon module installation

Configuration

After installation, you'll need to configure at least one validation service:

  1. Go to Email Validation → Configuration → Validators
  2. Select a validator and enter your API key (if using an API-based service)
  3. Set the validator as active

For more detailed configuration options, refer to the documentation of the individual modules.
