What this module does

Public web endpoint and form for single-address and bulk email validation. Submit one or many addresses and get a result per record using any validator configured in the suite.

Bulk paste field

Paste multiple addresses (one per line) and validate the whole list in one request.

Single-address form

Type one email and validate immediately, useful for ad-hoc checks.

Choose the validator

Pick a specific validator from the dropdown or leave it on Automatic to use the rule engine.

Public route

Endpoint exposed at /email_validation/validate, callable from any external system.

Public web form — Validator dropdown, bulk-paste textarea, Validate buttons.

Part of the Email Validation Suite

This module is one of 11 modules that add email address validation to every relevant Odoo model. Install the bundle to get the full set.
